The report script picks this up within the hour.

Setup (once)

  1. Add a user for the report under Users & access (role Head of Department), e.g. vanreports@kandymyst.com.
  2. Sign in to Google as kandymystservices@gmail.com → script.google.com → New project → paste MonthlyReport.gs.
  3. Project settings → Script properties: FIREBASE_API_KEY, FIREBASE_PROJECT_ID, REPORT_EMAIL, REPORT_PASSWORD.
  4. Run testNow (allow the permissions), then run setupTrigger once. The status above turns "Connected".

Backup

Downloads every user, vehicle, run, setting, trip, request, alert and log as one JSON file. Keep it somewhere safe (it contains staff names and phone numbers). GPS route points are not included.

About the audit log

Every change made by an administrator in this dashboard is recorded here, with who and when: users, roles, passwords, vehicles, runs, settings, announcements and reports. Entries cannot be edited or deleted.
